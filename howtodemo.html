👉 ใส่ไฟล์: ภาพเอกสารตรง/แบนราบที่สแกนมา หน้าเดียวกันกับช่องที่ 2
(เช่น pair1_thai_tax_invoice_flat.jpg หรือ pair2_aurora_invoice_flat.jpg)
➡️ ฝั่งขวา: Pipeline Settings (การตั้งค่า)
การเลือกโหมด (Radio Button)
⚪ Auto — ภาพเดียว (Contour): ใช้รูปเดียว หามุมด้วย Canny + Contour
⚪ Reference — 2 ภาพ (SIFT + RANSAC): ใช้รูปคู่ จับคู่ด้วย SIFT + RANSAC
การตั้งค่า Feature (สำหรับโหมด Reference)
• Feature Extractor: เลือก SIFT (หรือ ORB)
• Matcher: เลือก BFMatcher (หรือ FLANN)
• Lowe's Ratio Threshold: สไลเดอร์ตั้งไว้ที่ 0.75
ปุ่มแอคชันหลัก

2. สแกนใบเสร็จภาษีไทย Siam Vision (Auto) Auto 06_thai_tax_invoice_photo.jpg — ไม่ต้องใส่ — เอกสารไทย A4 แนวตั้ง ดัดมุมมองและตัวหนังสือคมชัด
3. สแกนบทความวิชาการ/สูตรเลข (Auto) Auto 04_academic_research_paper.jpg — ไม่ต้องใส่ — โชว์สูตรและกราฟ จากนั้นเลือกฟิลเตอร์ Clean B&W
4. SIFT + RANSAC ใบเสร็จไทย (เกณฑ์หลัก) Reference pair1_thai_tax_invoice_skewed.jpg pair1_thai_tax_invoice_flat.jpg เส้นเขียว Inliers 120 คู่ (81.6%) เมทริกซ์ H 3x3

7. ทดสอบโต๊ะทำงานรก (Edge Case 2) Auto edge2_cluttered_desk.jpg — ไม่ต้องใส่ — ระบบใช้ Fallback minAreaRect ตีกรอบสำเร็จ ไม่แครช

ที่ฝั่งขวาบน สลับ Radio Button เป็น: "Reference — 2 ภาพ (SIFT + RANSAC)"

4
กดปุ่ม "🚀 Run Scan Pipeline"
จุดที่ต้องพูดกับอาจารย์ (ห้ามข้าม): ชี้หน้าต่าง Feature Matching Visualization บอกว่าเส้นสีเขียวคือ Inliers จาก RANSAC ถึง 120 คู่ (81.6%) ที่จับคู่ข้อความภาษาไทยและตารางได้อย่างถูกต้อง และแสดงค่า Homography Matrix $H \in \mathbb{R}^{3 \times 3}$ ที่คำนวณได้
